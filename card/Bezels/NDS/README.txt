# Nintendo DS Overlays

Add .png overlay files to this folder.
Pick one in Settings > Screen > Nintendo DS > Overlay, or in the in-game menu while playing.

There is NO coverage or alpha limit: stylus touch screen borders, dual-screen frames,
and scanlines are all supported.

Recommended resolution:
  640 x 480 (4:3 devices)
  720 x 480 (3:2 devices)

Game viewport alignment on 640 x 480 screens:
  Vertical layout (default dual): x 160, y 0, 320 x 480
  Top Only layout: x 0, y 0, 640 x 480
  Bottom Only layout: x 0, y 0, 640 x 480
  Side-by-Side layout: x 0, y 120, 640 x 240

Integer Scale:
Overlays are displayed when Integer Scale is off, and hidden when Integer Scale is on.
