# Super Nintendo Overlays

Add .png overlay files to this folder.
Pick one in Settings > Screen > Super Nintendo > Overlay, or in the in-game menu while playing.

There is NO coverage or alpha limit: transparent-window bezels, CRT shadow masks,
scanlines, and themed borders are all supported.

Recommended resolution:
  640 x 480 (4:3 devices)
  720 x 480 (3:2 devices)

Game viewport alignment on 640 x 480 screens:
  Fit / Sharp Fit: x 0, y 0, 640 x 480 (fills 4:3 screen)

Integer Scale:
Overlays are displayed when Integer Scale is off, and hidden when Integer Scale is on.
